# المنحل

**Resala STEM Sub Branches — Season 7**

موقع ثابت عربي بالكامل. استضافة GitHub Pages فقط.

## تشغيل
```
node setup.js
npm install
npm run dev
```

## نشر
```
git init
git add .
git commit -m "init"
git branch -M main
git remote add origin <repo-url>
git push -u origin main
```

ثم في GitHub: Settings → Pages → Source: GitHub Actions
